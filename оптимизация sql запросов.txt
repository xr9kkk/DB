классификация индексов
логические
	одна(простой) или несколько колонок (составной)
	уникальные или неуникальные
	функциональные
физические
	кластерные и некластерные
	партиционированные и непартиционированные
	б - дерево
	битовые карты
	пространственные индексы для работы с данными пространственных типов данных
	инвертированные индексы - полнотекстовый индекс
	частичный индекс
	include index
	null index
	
	
null значения не индексируются в большинстве случаев, в постгрессе можно индексировать null
postgres не поддерживает bit map index
 	
индексы в постгре
б дерево
hash
gin - generalized inverted index - обобщенный инвертированный индекс (используется для json и массивов, то есть там, где у нас есть разделенные данные)
brin - block ranged index - индекс зон блоков (получаем не точное значение, а получаем зону в которой лежит наше значение, потом по этой зоне ищем) 
gist - generalized search tree - обобщенное дерево поиска(используем для координат)
sp gist - space partitioned GIST - с секционированием пространства
для хэша ищет только по равенству(логично епта)
